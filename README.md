# ✊ Rock Paper Scissors

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and test your luck!

## 🌐 Live Demo

Play the game here: https://jeri00712.github.io/Rock-Paper-Scissors/

## 📌 About the Project

Rock Paper Scissors is a classic hand game where a player competes against the computer by choosing one of three options: Rock, Paper, or Scissors.

The game compares both choices and displays the result as a win, loss, or draw.

## ✨ Features

- 🎮 Play against the computer.
- ✊ Choose Rock, Paper, or Scissors.
- 🤖 Computer generates a random choice.
- 🏆 Displays whether you win, lose, or draw.
- 📱 Simple and user-friendly interface.
- ⚡ Instant results using JavaScript.

## 🛠️ Technologies Used

- **HTML5** – Structures the game.
- **CSS3** – Styles the interface.
- **JavaScript** – Implements game logic and computer choices.
